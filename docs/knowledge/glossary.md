# 术语表

| 术语 | 精确定义 | 首次项目落点 |
| --- | --- | --- |
| ADR | Architecture Decision Record，记录有后果的技术决策。 | M0 |
| Context | Go 中传递取消、截止时间和请求级元数据的对象。 | M0 |
| 幂等 | 同一请求执行一次或多次，得到等价业务效果。 | M1–M2 |
| SLI | 可量化的服务质量指标。 | M4 |
| SLO | SLI 在给定窗口内的目标。 | M4 |
| Error Budget | SLO 允许消耗的失败余量。 | M4 |
| Span | 一段有开始和结束时间的追踪操作。 | M3 |
| Trace | 由关联 span 组成的一次端到端请求链路。 | M3 |
| Cardinality | 指标标签可取值组合的数量，高基数会增加存储和查询成本。 | M3 |
| Reconciliation | 控制器不断比较期望状态和实际状态并使其收敛的过程。 | M5 |
