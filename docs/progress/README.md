# 进度记录规则

`current.md` 是唯一的当前交接页，始终反映下一次工作应从哪里开始。

`handoffs/` 仅在协作式手敲代码时使用：其中可临时保留一个短小完整的代码接力稿，防止会话或网络中断。接力稿一旦已在目标源码路径落地并完成约定验证，就必须删除；完整实现仍只以源码和 Git commit 为准。

每个有效工作会话结束时：

1. 更新 `current.md` 的完成项、验证结果、阻塞项和下一步。
2. 从 `../templates/session.md` 复制一份到 `sessions/YYYY-MM-DD-主题.md`。
3. 将文档与同一会话的代码一起提交；不要把“进度”只留在聊天记录中。

不要记录密码、令牌、IP、代理地址或其他私有运维信息。
